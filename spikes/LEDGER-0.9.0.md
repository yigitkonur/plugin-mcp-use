## Codex review (once, `review --wait --base main`)
Six findings. Fixed (each with a test that fails on the old code, `tests/probe-fixes.test.mjs`): the unauthenticated CG-A01 probe sent the bearer token; failed sample calls were recorded as successes and ignored by `--diff`; `--snapshot` did not create its parent directory (the documented migration baseline path failed on a fresh repo); `drift.yml` recorded `tee`'s exit status so drift never opened an issue; a stdio probe of a wrapped command left its server running. Not fixed (does not affect a row): the HTTP client reads an SSE response with `res.text()`, so a server that keeps the stream open after sending the result would hit the 15 s timeout (mcp-use and the official SDK close the stream per response). Rows 8 (probe parts) and 10 were re-run after the fixes: scans and probes unchanged, F02 and F03 parity diffs unchanged (annotations only, 0 call differences).

Evidence tags: `[live]` = run with `mcp-use dev`, `build`/`start`, `mcp-use screenshot`, `curl`, `mcp-use-probe` on a copy of fixture F14 (a view-backed tool with `@openai/apps-sdk-ui`); `[types]` / `[src]` = a file under `node_modules/mcp-use/dist/`; `[inspector]` = a string read from the installed `@mcp-use/inspector` 20.3.22 bundle (code read, not driven in a browser).
